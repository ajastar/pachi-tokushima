# 徳島県パチンコ・スロット情報収集ツール

徳島県内のパチンコ・スロット店舗のデータを自動収集し、分析レポートを作成するツールです。
「みんレポ」の出玉データと「P-WORLD」のイベント情報を統合し、おすすめ店舗の提案やトレンド分析をダッシュボード形式（HTML）で出力します。

## 機能

- **データ収集**:
  - **みんレポ**: 過去30日間の差枚数、人気機種情報を取得。
  - **P-WORLD**: 本日のイベント、新台入替、リニューアル情報を取得。
- **データ分析・統合**:
  - **推奨店舗算出**: 直近の出玉実績と本日のイベント情報を組み合わせて、おすすめ度をスコアリング。
  - **アナスロ連携**: 対応店舗の「アナスロ」データページへの直接リンクを自動生成。
  - **トレンド分析**: 人気機種の傾向を集計。
- **レポート生成**:
  - スマホ閲覧に最適化されたHTMLレポート (`tokushima_pachi_report.html`) を生成。
  - 外部サイト（ホールナビ、みんパチ等）へのリンク集も統合。

## 必要要件

- Python 3.x
- 必要なライブラリは `requirements.txt` に記載されています。

## インストール方法

1. リポジトリをクローンまたはダウンロードします。
2. 必要なライブラリをインストールします。

```bash
pip install -r requirements.txt
```

## 使い方

以下のコマンドを実行してレポートを生成します。

```bash
python generate_report.py
```

実行中に、高稼働店舗の「平均回転数」の手動入力を求められることがありますが、不要な場合はEnterキーでスキップ可能です。
処理が完了すると、同ディレクトリに `tokushima_pachi_report.html` が生成されます。ブラウザで開いて確認してください。

## ファイル構成

- `generate_report.py`: メイン実行スクリプト。
- `src/`: スクレイピングロジックやレポートテンプレートなどのソースコード。
- `tokushima_pachi_report.html`: 生成されるレポート（成果物）。
- `manual_data.json`: 手動入力したデータの保存場所。
